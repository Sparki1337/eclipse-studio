# Eclipse Manifest for Millennium (Eclipse Studio) v0.5.2

Встроенный плагин для Millennium, входящий в состав **Eclipse Studio**. Плагин добавляет кнопку **«Получить манифест»** на страницы игр в магазине настольного клиента Steam.

После нажатия плагин:

1. определяет AppID открытой игры;
2. получает ZIP-пакет через выбранный сервис Ryuu или HubCap;
3. помещает Lua-файлы в `Steam/config/lua` (с обратной совместимостью со `Steam/config/stplug-in` и `Steam/lua`);
4. помещает manifest-файлы в `Steam/depotcache`;
5. предлагает перезапустить Steam.

Дополнительно плагин:
- Поддерживает 12 встроенных тем оформления из Eclipse Studio;
- Показывает состояние игры и наличие обновления прямо на странице магазина;
- Сохраняет историю операций, позволяет удалить файлы выбранной игры и поддерживает режимы карточки `Full`, `Button` и `Eclipse`;
- Для HubCap рядом с кнопкой отображаются использованный дневной лимит и оставшееся число скачиваний;
- Поддерживает установку и обновление библиотек OpenSteamTool по Схеме 2 (с контролем файлов версий `version` и автоматическим сценарием `install-loader.ps1`);
- Позволяет синхронизировать библиотеки хуков Steam напрямую из облака GitHub.

## Требования

- Windows 10 или новее;
- установленный [Millennium](https://steambrew.app/);
- доступ к `generator.ryuu.lol`;
- PowerShell, входящий в Windows.

## Сборка

```powershell
npm install
npm run build
```

## Установка

Скопируйте всю папку `eclipse-manifest` в:

```text
<Steam>\millennium\plugins\eclipse-manifest
```

Затем:

1. полностью перезапустите Steam;
2. откройте настройки Millennium;
3. включите **Eclipse Manifest**;
4. ещё раз перезапустите Steam;
5. откройте страницу любой игры в магазине.

## Примечания

- Первая версия ориентирована на Windows.
- Кнопка появляется только на адресах `store.steampowered.com/app/<AppID>`.
- Строки `setManifestid` в Lua комментируются так же, как в модуле Eclipse Manifest, чтобы Steam мог обновлять данные.
- Если Steam изменит разметку магазина, селектор места для кнопки может потребовать обновления.
