# Сервер разработки и отладки UI (/ui-dev)

Этот скилл позволяет запустить локальный HTTP-сервер для мгновенного предпросмотра и отладки пользовательского интерфейса Eclipse Studio в обычном веб-браузере (Edge, Chrome, Firefox) без долгой компиляции Rust-бэкенда.

## 📌 Что предоставляет сервер:
1. **Полный мок системного API Tauri (`window.__TAURI__`)**:
   - Автоматически внедряется в HTML без изменения исходных файлов репозитория.
   - Поставляет реалистичные данные: библиотека Steam с 8 играми и постерами, каталог Crack Vault из 153 релизов с закреплёнными позициями, статусы VBS и 12 античитов, настройки тем и акцентов.
2. **Мгновенное применение изменений (Live Edit)**:
   - Все правки в `ui/*.js`, `ui/*.css`, `ui/*.html` отображаются сразу при обновлении страницы в браузере (F5).
3. **Белый акцентный цвет по умолчанию**:
   - Интерфейс стартует с темой `graphite` и чистым белым акцентом (`white`).

---

## 🚀 Порядок запуска:

1. **Запуск сервера**:
   Запустите сервер в фоновом режиме:
   ```powershell
   node tools/ui_dev_server.js --port 8080
   ```
   *Если порт 8080 занят, сервер автоматически выберет свободный порт.*

2. **Открытие в браузере**:
   Перейдите по адресу:
   [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

   *Для перехода к конкретному разделу можно передать параметр `?view=...`:*
   - `http://127.0.0.1:8080/?view=home` — Главная
   - `http://127.0.0.1:8080/?view=fix` — Online Fix
   - `http://127.0.0.1:8080/?view=saves` — Менеджер сохранений
   - `http://127.0.0.1:8080/?view=dlc` — DLC Unlocker
   - `http://127.0.0.1:8080/?view=lua` — Eclipse Manifest
   - `http://127.0.0.1:8080/?view=hypervisor` — Гипервизор
   - `http://127.0.0.1:8080/?view=files` — Кряки (Crack Vault)
   - `http://127.0.0.1:8080/?view=utilities` — Утилиты
   - `http://127.0.0.1:8080/?view=settings` — Настройки
